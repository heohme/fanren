# 凡人残图 V1.1 更新说明

发布日期：2026-07-19
当前正片：第 183 话

## 这次更新解决了什么

V1.1 把网站从“固定展示少量 UP 的内容页”推进为“凡人内容发现与推荐地图”。同时修复了连载篇章范围需要手工更新、远端数据更新后 Cloudflare Pages 未及时同步等问题。

## 主要更新

### 1. 全部 UP 名录

- UP 名录由原来的 12 位扩展为 237 位。
- 数据来源合并为“常驻追踪、历史发现、二创作者”三类。
- 每位 UP 都有独立内容页、B 站主页入口和可复制的专属链接。
- 支持按 UP 名、别名和内容标签筛选。

UP 标签根据已经收录的作品自动计算。某位 UP 没有显示某个分类，代表当前归档中尚未发现对应类型的作品，并不是遗漏了手工配置。

### 2. 推荐模式

解析区新增三组推荐：

- **本话先看谁**：优先展示已经更新当前集解析的作者。
- **稳定更新**：根据历史覆盖集数推荐持续创作的作者。
- **新道友**：从历史回填和二创发现中展示新面孔。

二创区新增本周热门、新人发现、沧海遗珠、活动专题、总榜与分类浏览。

推荐不只看累计播放量，也兼顾发布时间、作者体量、内容类型和作品新鲜度，降低新作品与小 UP 被总榜长期压住的概率。

### 3. 已看与未看

- 打开作品后会出现“✓ 已看”标记。
- 支持“只看未看”和“显示全部”切换。
- 浏览记录保存在当前浏览器本地，刷新页面后仍会保留。
- 当前版本不会上传个人浏览记录，也没有使用 Canvas、WebGL 或字体列表等强浏览器指纹。

更换浏览器、使用无痕模式或清理站点数据后，已看记录会重新开始。

### 4. 正片篇章自动更新

正在连载的最后一个篇章会根据最新正片集数自动延长，不再需要每周手工修改结束集数。第 183 话现已归入“慕兰之战 177—183 话”。

### 5. 加载速度优化

首页不再一次性塞入所有正片、解析和二创数据，而是在打开对应区域时再加载。

- 优化前首页静态文件约 949 KB。
- 优化后首页 HTML 约 19 KB。
- 正片、解析和二创分别按需加载。

这会明显降低首次打开页面时的下载和解析开销。

### 6. 自动部署链路

- GitHub 自动抓取任务在推送前会先同步远端 `main`，减少非快进推送导致的更新失败。
- 默认分享地址统一为 <https://fanrenmap.pages.dev>。
- Cloudflare Pages 继续监听 `main`，主分支更新后自动构建部署。

## 验证结果

- 内容分类回归测试通过。
- 二创发现策略测试通过。
- Next.js 生产构建通过。
- 第 183 话、推荐模式、全部 UP、作者专属入口、已看标记和刷新后保留均已在本地预览验证。
- 页面未发现浏览器警告或脚本错误。

## 下一步建议

1. **先观察推荐效果**：记录推荐位点击率、作者页打开率和“只看未看”的使用率，再调整推荐权重。
2. **接入匿名 UV/PV**：使用 Cloudflare Web Analytics 或 Worker + D1/Analytics Engine，避免采集高风险浏览器指纹。
3. **开放九国盟共建入口**：允许推荐 UP 或作品，先进入待审核队列，再进入正式收录与道友推荐榜。
4. **增加推荐理由解释**：让“本话有更、连续更新、新人发现、低播放高互动”等理由在卡片上更透明。
5. **建立版本更新节奏**：每个可感知版本新建一篇更新说明，日常小修只在同一篇文档追加“修订记录”。
